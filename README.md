# The Robot Apology

One robot apology in two lines: the exact small slip, and the lesson that follows from it. Run the builder:

```sh
python main.py
```

It verifies `entry.txt` against the gate and copies it to
`$MAKEFUN_OUTPUT_DIR/entry.txt`, printing a JSON receipt.
